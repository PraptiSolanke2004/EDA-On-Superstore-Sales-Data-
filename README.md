# 📊 Exploratory Data Analysis (EDA) on Superstore Sales Data

## 📊 Project Overview

This project presents a complete **Exploratory Data Analysis (EDA)** of a real-world Superstore Sales dataset using **Python**. The project focuses on cleaning, exploring, and visualizing sales data to identify important **sales trends, profit relationships, customer segments, regional performance, and outliers**.

## 🔑 Key Features

* 📥 Load and explore the Superstore dataset
* 🔍 Display first 10 rows, shape, columns, and data information
* 🧹 Check and handle missing values
* 🔄 Check data types and duplicate records
* 📊 Category, Sub-Category, Segment, Region, and State analysis
* 📈 Sales vs Profit and Discount vs Profit scatter plots
* 📉 Histograms for Sales, Profit, Quantity, and Discount
* 🔥 Correlation heatmap for numerical variables
* 📦 Boxplots for identifying Sales, Profit, and Discount outliers
